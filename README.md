# school-bot — Where WITHUS Began

A school chatbot prototype built together with fellow Manila Hankuk Academy students in September 2025. This was our first attempt at solving a problem we all shared: school information (schedules, meals, announcements) was scattered everywhere and nowhere.

## What it is

A Next.js app where students could ask school-related questions and get answers from a chatbot. Simple by design — the goal was to prove the idea and learn to build as a team.

## Why it matters (to me)

This prototype taught me two things:

1. **The problem was real.** Students used it and immediately asked for more — meals, timetables, exam dates.
2. **A prototype is not a product.** The bot confidently made things up when it didn't know an answer, and we had no process for keeping school data current.

Both lessons fed directly into [**WITHUS**](https://github.com/wonsun-max/mhAA-chatbot) ([live](https://mhawithus.shop/)) — the production platform I later built solo, where the assistant is restricted to a verified school database precisely because of what I saw go wrong here.

## Tech stack

Next.js · TypeScript

## Context

Team project with MHA students, Grade 12. Kept as-is — this repo is the "before" picture of the WITHUS story.
